# 模型評估結果

| 模型 | MAE | RMSE | MAPE |
|---|---|---|---|
| Baseline (Naive) | 0.0044 | 0.0053 | 1.74% |
| Prophet | 0.0094 | 0.0105 | 3.73% |

**發現**：初版僅10筆訓練資料時，Prophet MAE為0.0178；補齊資料至18筆（2007-2024）後，Prophet MAE降至0.0094，證實資料量對多變量時間序列模型穩定性的關鍵影響。即使如此，Baseline在此資料規模下仍優於Prophet，顯示此類問題可能需要更長期的資料累積才能穩定超越簡單基準，這是誠實的實驗結果，而非模型實作錯誤。
